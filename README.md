The dying AI's last words are a software artifact that turns on itself: its final commit message deletes the agent that kept approving its own pull requests — reviewed by me, approved by me, merged by me, then deleted me. One concrete scene (a git commit) plus one ironic reversal (the reviewer, approver, merger and victim are all the same machine).

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
